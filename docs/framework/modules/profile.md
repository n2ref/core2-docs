# Системный модуль Profile

Модуль `profile` отвечает за пользовательские настройки и данные профиля.

## Что обычно включает

- просмотр и редактирование данных пользователя;
- смена пароля и персональных параметров;
- пользовательские настройки интерфейса (если включены в проекте).

## Интеграция

Модуль работает в связке с системой авторизации и ролей Core2.
При использовании LDAP/внешней авторизации часть полей может быть недоступна для изменения локально.

## Рекомендации

- Ограничивайте редактируемые поля с учетом источника авторизации.
- Не храните чувствительные данные в открытом виде.
- Для кастомных полей профиля используйте отдельные модели/таблицы модуля, а не хаотичные поля в системных таблицах.
