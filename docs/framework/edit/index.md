# Поля формы (`Edit`)

Типы полей определяются в `core2/inc/classes/class.edit.php` (ветка рендера по `$value['type']`).

В этом разделе каждый тип вынесен в отдельный файл.

## Модификаторы типа

Поддерживаются служебные суффиксы:

- `_hidden`
- `_auto`
- `_default`

Пример: `text_hidden`, `date_auto`.
