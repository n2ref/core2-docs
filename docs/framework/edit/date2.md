# Дата v2 (date2)

Расширенный вариант поля даты.

## Пример

```php
$edit->addControl('Поле', 'date2');
```

## Примечания

- Тип поддерживается в `core2/inc/classes/class.edit.php`.
- Для конкретных параметров (`in`, `attr`, `readonly`, сохранение) смотрите код модуля и примеры рядом по документации.
